# Construction Business Blueprint Portal V2

This folder is the implementation brief for a major upgrade of Marc Watters's existing portal.

V2 is an evolution of the current product, not a replacement. It retains the dark-first Construction Business Blueprint identity, existing routes, feature names, client journey and administrative structure. The objective is to make the portal feel substantially more premium, coherent, responsive and reliable without asking Marc or his clients to learn a different product.

## Product principle

The intended client reaction is:

> This is clearly the Construction Business Blueprint portal I already know, but it now feels like a premium, purpose-built product.

The intended reaction is not:

> Marc has moved me into a completely different system.

## Recommended starting point

Start with the safe wow-factor release. It is deliberately limited to presentation, hierarchy, responsiveness and interaction feedback. It avoids changes to the database, authentication, file storage, API contracts and coaching methodology.
